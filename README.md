# Asistente de Migración Inteligente Alodiga

Simulación interactiva de la migración de un core bancario (IBS u otro) hacia Alodiga Core, con agentes de IA.

- Conexión simulada al core de origen y a servidores o grupos de destino
- Switch-over contra migración incremental, con el mismo reloj
- Equipo de agentes por fase, con el detalle exacto de cada operación y decisiones para el usuario
- Router de canales en vivo (ATM, POS, switch, pago móvil, P2C, ACH, app, taquilla)

Es un sitio estático de un solo archivo (`index.html`). Todos los datos son de ejemplo y la conexión no abre ninguna red real.
